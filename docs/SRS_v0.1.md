# 소프트웨어 요구사항 명세서(SRS) v0.1 - 교내 분실물 관리 서비스

## 1. 기능 요구사항

| ID | 기능 요구사항 | 우선순위 | 근거 | 비고 |
|---|---|---|---|---|
| FR_00 | 시스템은 이용자가 분실물의 보관 여부를 조회할 수 있도록 제공해야 한다. | 높음 | NEEDS_1, SC1 | 검색 조건은 추후 확정한다. |
| FR_01 | 시스템은 조회 결과에 해당 분실물의 보관 위치를 표시해야 한다. | 높음 | NEEDS_1, SC1 | 공개 가능한 위치 정보 범위는 정책을 따른다. |
| FR_02 | 시스템은 습득 학생이 습득한 물품 정보를 앱에서 즉시 등록할 수 있도록 제공해야 한다. | 높음 | 확정 사항 | 필수 입력 항목은 추후 확정한다. |
| FR_03 | 시스템은 행정 담당자가 등록된 분실물 정보를 관리할 수 있도록 제공해야 한다. | 높음 | NEEDS_2, SC2 | 수정·삭제 가능 여부와 권한은 추후 확정한다. |
| FR_04 | 시스템은 각 분실물에 대해 `보관 중` 또는 `인도 완료` 상태를 기록할 수 있어야 한다. | 높음 | NEEDS_3, SC3 | 상태 변경 권한과 정정 절차는 추후 확정한다. |
| FR_05 | 시스템은 조회 결과에서 보관 중인 물품과 인도 완료 물품을 구분하여 표시해야 한다. | 높음 | NEEDS_3, SC3 | 상태별 조회 노출 방식은 추후 확정한다. |
| FR_06 | 시스템은 분실 학생에게 보관 담당 부서와 문의 방법을 안내해야 한다. | 높음 | NEEDS_4, SC6 | 담당 부서명, 연락 수단, 운영시간 등 표시 항목은 추후 확정한다. |
| FR_07 | 시스템은 행정 담당자가 분실물 센터로 접수된 습득 물품 정보를 등록할 수 있도록 제공해야 한다. | 높음 | 확정 사항, NEEDS_2, SC2 | 센터 접수 물품의 필수 입력 항목은 추후 확정한다. |

## 2. 비기능 요구사항(품질 요구사항)

| ID | 품질 특성 | 비기능 요구사항 | 검증 기준 | 근거 |
|---|---|---|---|---|
| NFR_00 | 개인정보 보호 | 조회 화면은 개인 휴대전화 번호를 공개해서는 안 된다. | 조회 화면 및 테스트 데이터에 개인 휴대전화 번호가 표시되지 않는다. | NEEDS_6, SC8 |
| NFR_01 | 개인정보 보호 | 시스템은 실제 개인정보를 저장하거나 처리해서는 안 되며, 가상 데이터만 사용해야 한다. | 저장소·화면·테스트 데이터에 실제 개인정보가 포함되지 않는다. | C_1 |
| NFR_02 | 보안/연동 범위 | 시스템은 실제 학교 인증 시스템과 연동하지 않아야 한다. | 인증 연동 API, 실계정 로그인 또는 학교 계정 정보가 구현 범위에 포함되지 않는다. | C_1 |
| NFR_03 | 사용성 | 분실 학생은 행정실을 방문하기 전에 보관 여부, 보관 위치 및 문의 방법을 화면에서 확인할 수 있어야 한다. | 대표 분실물 조회 시 해당 정보를 화면에서 확인할 수 있다. | NEEDS_1, NEEDS_4 |
| NFR_04 | 운영 효율성 | 물품 등록 과정은 행정 담당자의 반복 문의 및 등록 업무 부담을 줄이는 방향으로 설계해야 한다. | 등록 단계 수, 소요 시간 및 개선 목표는 측정 방법을 포함해 추후 합의한다. | NEEDS_7 |
| NFR_05 | 정확성 | 표시되는 보관 상태는 등록된 물품의 최신 상태와 일치해야 한다. | 상태를 변경한 뒤 조회 화면에서 변경된 상태가 일관되게 표시된다. | NEEDS_3 |

## 3. 정책

| ID | 정책 | 적용 대상 | 근거 | 상태 |
|---|---|---|---|---|
| Pol_00 | 조회 화면에 공개하는 정보는 분실물 확인과 문의에 필요한 최소 범위로 제한한다. | 분실물 조회 화면 | NEEDS_6, S4 | 공개 항목 세부 목록 확정 필요 |
| Pol_01 | 개인 휴대전화 번호는 조회 화면에 공개하지 않는다. | 모든 조회 및 안내 화면 | NEEDS_6, SC8 | 확정 |
| Pol_02 | 이용자 문의는 개인 연락처 대신 보관 담당 부서와 공식 문의 방법으로 안내한다. | 문의 방법 안내 | NEEDS_4, SC6 | 담당 부서·연락 수단 확정 필요 |
| Pol_03 | 서비스 데이터는 가상 데이터로 한정하며 실제 개인정보를 사용하지 않는다. | 데이터 등록·저장·표시 | C_1 | 확정 |
| Pol_04 | 실제 학교 인증 연동은 본 버전의 범위에서 제외한다. | 인증 및 계정 기능 | C_1 | 확정 |
| Pol_05 | 사진 등록·비슷한 분실물 검색 및 사진 매칭 결과 자동 알림은 본 버전에서 제공하지 않는다. | 이미지·알림 기능 | SC5, SC7 | 확정(후속 개선 후보) |
| Pol_06 | 습득물을 맡길 장소 안내 기능의 포함 여부는 기존 안내 체계와 프로그램 안내 필요성을 확인한 후 결정한다. | 습득물 안내 | NEEDS_5, SC4 | 미정 |
| Pol_07 | 분실물 정보의 필수 입력 항목, 역할별 처리 권한 및 상태 정정 절차는 서비스 운영 책임자가 확정한다. | 등록·관리·상태 변경 | NEEDS_2, NEEDS_3 | 미정 |
| Pol_08 | 습득물 등록은 습득 학생의 앱 직접 등록과 행정 담당자의 분실물 센터 접수 물품 등록 경로를 모두 제공한다. | 습득물 등록 | 확정 사항 | 확정 |
